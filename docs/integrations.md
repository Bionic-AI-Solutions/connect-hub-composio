## Adding more

```bash
npm run catalog:add -- hubspot notion asana linear clickup monday trello airtable discord salesforce
npm run catalog:add -- --all     # every app piece on npm (~750 apps; several hundred MB)
```

Restart the server; new toolkits appear automatically. Each OAuth one needs a provider app (platform env vars or a
tenant auth config). Check `npm run catalog:list` for the provider family name used by `OAUTH_<PROVIDER>_*`.

## Writing a native toolkit

Use a native toolkit when no piece exists or the piece is weak. See `src/catalog/native/cloudflare.ts`: declare auth
schemes and tools (name, JSON Schema input, `run(args, auth)`), then add the export to `NATIVE_TOOLKITS` in
`src/catalog/registry.ts`.
